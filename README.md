# CareLink

Plateforme de santé digitale – Application Patient

## Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- Design System médical professionnel

## Applications prévues

1. **Patient** (en cours)
2. Hôpital / Médecin
3. Marketplace Pharmacie

## Démarrage

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000)
