# CareLink Shared — Package Partagé

Ce package contient les ressources partagées par les 3 applications CareLink :
- Interfaces et types TypeScript dérivés du schéma Supabase
- Constantes métier (rôles, statuts de commande, codes devises FCFA/XOF)
- Formules utilitaires (calcul géodésique Haversine, formateurs de date et monétaire)
- Schémas de validation (Zod)
